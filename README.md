# Couronnes & Arcanes — V2.7.1

Jeu original de stratégie fantastique à cartes, jouable en solo hors ligne.

## Fichiers importants

- `JOUER.html` : jeu autonome.
- `index.html` et `src/` : version modulaire pour le développement.
- `AGENTS.md` : consignes permanentes, notamment coordination multi-agents.
- `docs/ETAT_PROJET.md` : état courant et points de reprise.
- `CHANGELOG.md` : historique des évolutions.
- `docs/BIBLE_DU_JEU.md` : règles et identité du jeu.

## Exécution et tests

```bash
npm test
npm run test:parity
npm run build
```

Ne pas modifier simultanément les mêmes fichiers dans deux sessions. Utiliser une branche et une pull request par session.
