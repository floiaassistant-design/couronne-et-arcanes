# Illustrations actives

Aucune illustration de personnage n'est active après la remise à zéro du
20 octobre 2026. Le jeu montre un emplacement neutre autonome.

Les nouveaux fichiers doivent être approuvés individuellement, déclarés dans
`assets/artwork.json` et associés explicitement dans `src/visuals.js`.
Chaque entrée conserve clé, cible, version, dimensions, poids, SHA-256,
provenance, droits et reçu humain. Le builder refuse les WebP non catalogués.

Les anciens fichiers restent récupérables dans l'historique Git ; ils ne sont
plus des modèles ou des approbations de la nouvelle production.
